# FAQ

### How is scrappy different from other scrapers?

scrappy is built from scratch in Go for **bulk operations** -- it fans out across 55+ sites concurrently, processes thousands of postings, and ships results to disk. Concurrency is via goroutines (not OS threads), memory is cap-aware, and every scrape exports to structured formats (JSONL, CSV, XLSX, Parquet) without an intermediate DataFrame.

### Can I use it as a Go library?

Yes. Import `github.com/arinbalyan/scrappy/pkg/scrappy` for programmatic use:

```go
import "github.com/arinbalyan/scrappy/pkg/scrappy"

engine := scrappy.NewEngine()
jobs, err := engine.Scrape(ctx, model.ScraperInput{
    Sites:        []model.Site{model.SiteIndeed, model.SiteRemoteOK},
    SearchTerm:   "software engineer",
    Location:     "Remote",
    ResultsWanted: 500,
})
```

### Why are some sites returning 0 results?

Five sites need API keys (Adzuna, Careerjet, InfoJobs, Findwork, Arbeitsagentur). If the key is not set, the engine skips the site with a WARN message. Other possibilities:

- The site is geo-restricted (ZipRecruiter is US/Canada only)
- The site is behind a challenge (CAPTCHA, Cloudflare)
- Rate limiting is throttling responses
- The search term produced no matches

Run with `--log-level DEBUG` to see per-site telemetry.

### How do I scrape more than the default sites?

```bash
# All 55+ sites
scrappy --sites linkedin,indeed,remoteok --search "engineer"

# Or omit --sites entirely to scrape every site
scrappy --search "engineer" --results-wanted 500
```

### What is the memory impact of running 55 sites?

Each scraper uses ~2 KB goroutine stack + HTTP response buffers. With 8 concurrent scrapers, expect 100-300 MB RSS. Use `--memory-cap` to cap concurrency:

```bash
scrappy --memory-cap 512MB --search "engineer" --results-wanted 500
```

See [016-Memory-Management.md](016-Memory-Management.md) for details.

### Can I run this in Docker?

```bash
docker build -t scrappy .
docker run scrappy --sites indeed --search "golang" --results-wanted 200 --format csv --out /data/jobs.csv
```

See [003-Installation.md](003-Installation.md) for the full Docker guide.

### How do I get emails from job postings?

Email extraction runs automatically on every job description. The pipeline:

1. Regex scan for `user@domain` patterns (handles `[at]` obfuscation)
2. Normalization and deduplication
3. MX DNS lookup to verify the domain accepts mail
4. Optional company-page enrichment (`--email-enrich`)

Use `--email` to keep only jobs with at least one email address.

See [010-Email.md](010-Email.md) for details.

### How do I avoid getting blocked?

- Use proxies: `--proxy socks5://user:pass@host:1080`
- Respect rate limits: `--site-rps linkedin:1,indeed:10`
- User-agent rotation happens automatically (3 Chrome/Safari variants)

See [013-Proxy.md](013-Proxy.md) for detailed guidance.

### What is fail-open?

When a site returns an error (429, 5xx, CAPTCHA), the engine **continues** scraping other sites instead of aborting the entire run. The failed site is recorded in telemetry with a `FailOpenReason` (challenge_detected, rate_limited, access_denied, timeout, unknown).

```go
// After the run, inspect telemetry
engine.Telemetry()
```

You can disable fail-open with `SetSiteFailOpen(false)` in library mode.

### Can I schedule this?

Yes. Use your system scheduler:

```bash
# crontab -- hourly
0 * * * * scrappy --sites indeed,remoteok --search "engineer" \
  --results-wanted 200 --format jsonl --out /data/$(date +\%Y\%m\%d\%H).jsonl \
  --non-interactive

# systemd timer -- daily at 6 AM
[Unit]
Description=Scrappy daily scrape

[Timer]
OnCalendar=*-*-* 06:00:00

[Install]
WantedBy=timers.target
```

### What output formats are available?

JSONL (default), CSV, XLSX, and Parquet. See [009-Export-Formats.md](009-Export-Formats.md) for details.

### How does deduplication work?

Two strategies:

- **URL dedup** (`--dedup`): If two sites return the same job URL, only the first is kept. O(1) lookup.
- **Company dedup** (`--dedup-by-company`): Keeps one posting per company, preferring the highest quality score.

Both run cross-site and are thread-safe.

See [014-Dedup.md](014-Dedup.md).

### How do I bypass anti-bot challenges?

Some sites (monster) block plain HTTP with DataDome. scrappy includes an **optional browser fallback** using Playwright:

```bash
cd scripts && npm install   # one-time setup
```

After installing, these scrapers automatically use headless Chromium when the HTTP path is blocked. The feature is auto-detected at runtime -- no CLI flag needed. See [012-Scraping.md](012-Scraping.md#browser-fallback-anti-bot).

### Can I filter by quality?

Yes. `--min-score 60` drops postings below a deterministic 0-100 score computed from salary, apply method, email match, freshness, description length, and agency status. See [011-Quality.md](011-Quality.md).

### What size scrape is realistic?

A single run across all 55+ sites with `--results-wanted 10000` and `--memory-cap 1GB` typically completes in 2-5 minutes and produces 5,000-10,000 postings (many sites return fewer than their requested max). For larger runs, increase `--results-wanted` and add proxies.

### How do I control rate limits?

Two flags control rate limiting:

- `--max-rps`: Global cap on requests per second (clamped 2-16).
- `--site-rps`: Per-site overrides in `site:rps` format (e.g. `linkedin:1,indeed:10`).

See [012-Scraping.md](012-Scraping.md) for per-site defaults.
