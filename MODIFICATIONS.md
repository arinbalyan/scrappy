# Modification policy

scrappy is licensed under the GNU General Public License, version 3 or later.
Copyright (c) 2026 Arin Balyan.

Every distributed modification must retain the copyright and license notices,
state that the file was changed, and include the date of the change. Git
tracks the authoritative date for every commit. Release notes and the
per-source behavior documents record functional changes.

Rust sources carry an SPDX identifier. Files changed during hardening on
2026-11-27 carry a dated modification notice in their history and, where the
file already has a header block, in that header.

Do not remove the SPDX identifier or the copyright notice when redistributing
this project or a modified version.
