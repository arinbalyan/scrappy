# ATS slug candidate audit

Research date: 2026-11-27 (UTC). Scope: every source that declares a `slugs` seed in `src/sources/manifests/`, including the ATS family and the `html_static` ATS source. Most listed manifests ship the placeholder `example-co`, `example-board`, or `example-company` rather than a usable tenant. One non-ATS source already carries a real seed, `internshala` (`engineering`). The endpoint column gives the exact manifest request pattern; braces mark the seed substitution.

Verification legend used in the table:

- **Published** — the slug appears in a current, dated public source as a live board or in a live-tested request example. These are third-party observations, not HTTP probes run from this workspace.
- **Unverified** — the ATS has a public slug scheme, but no current public tenant slug was confirmed for this audit.
- **Private key** — the seed is a credential issued by the vendor, not a public board identifier.
- **No direct probe** — outbound DNS and TCP from this sandbox failed for public hosts (`curl` returned exit 6 / exit 7), so no HTTP status or record count could be measured here. Counts in the notes are those reported by the cited public sources on their own test dates.

## Families that cannot be seeded from public tenants

- **ADP (`adp`)** — public `myjobs.adp.com` career-site slugs exist, but the manifest targets the older `workforcenow.adp.com ...?cid=<guid>` product, whose `cid` is a tenant GUID. No public `cid` was found. Seeding requires a real Workforce Now tenant GUID.

- **Recruiterflow (`ats-recruiterflow`)** — the seed is the `RF-Api-Key` credential itself. There is no public board slug that grants API access, so a seed requires a vendor-issued key. This is a credential, not a discoverable tenant.

- **JazzHR (`jazzhr`)** — keyed source with `JAZZHR_API_KEY`; no slug is involved.

- **Freshteam (`freshteam`)** — the tenant subdomain is public, but the `/api/job_postings` route needs a bearer token. Public tenant names alone are not enough.

- **Comeet (`comeet`)** — the seed is a company UID and the request also needs a public token. Comeet publishes a sandbox UID/token pair for mock data; real boards require values from the employer's Careers Website settings.

- **Crelate (`crelate`)** — the manifest has no `{slug}` substitution. It requires `CRELATE_API_KEY`, and public portal slugs identify the employer site rather than the API account.

- **SAP SuccessFactors (`ats-successfactors`)** — OData v2 access is governed by tenant role-based permissions. Public postings sit on custom Career Site Builder domains. No unauthenticated public OData instance was found.

- **Oracle (`ats-oracle`)** and **UKG (`ats-ukg`)** — real tenants exist, but the manifest patterns do not match the publicly observed routes.
